# Guild ledger artwork

Parchment.tga and Leather.tga are original generated artwork for Guild Gear Memory's aged-book interface. Each is an uncompressed, 24-bit RGB, 1024 by 1024 TGA. They are loaded locally by the normal addon UI; no download or external runtime component is required.

The PNG artwork references are kept under tools/ledger-art for development. Only the TGA textures are needed in the distributed addon folder.
